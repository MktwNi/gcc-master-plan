# GCC Master Plan (CFO)

หน้าเว็บสำหรับกรอกแผนการทวนสอบ CFO แล้วออกเป็น PDF

ใช้งานได้ที่ https://mktwni.github.io/gcc-master-plan/

- เข้าสู่ระบบด้วยบัญชีเดียวกับ GCC Registry แล้วเคสจะเก็บในแท็บ `master_plan` ของ Google Sheet ของทีม เข้าถึงได้เฉพาะบัญชีที่มีสิทธิ์ Master Plan
- ถ้าไม่เข้าสู่ระบบ ข้อมูลจะอยู่เฉพาะในเบราว์เซอร์ของเครื่องนั้น
- repo นี้เป็นสาธารณะ ห้ามเพิ่มไฟล์แผน (`.json`) หรือ PDF ของลูกค้า
